## 1. 벡터 연산 3가지

| 연산 | 결과 | 뜻 | 그래픽스에서 쓰는 곳 |
|---|---|---|---|
| 덧셈 `a + b` | 벡터 | 이어 붙이기 | 점 + 이동 = 옮겨진 점, `b − a` = a에서 b로 가는 방향 |
| 내적 `a · b` | **숫자** | 두 방향이 얼마나 같은가 ($\lvert a\rvert\lvert b\rvert\cos\theta$) | 사잇각, **조명 밝기**(5주차) |
| 외적 `a × b` | **벡터** | 두 벡터에 모두 수직 (길이 = 평행사변형 넓이) | **삼각형 법선**, 카메라 축(4주차) |

- 내적: 같은 방향이면 최대, **수직이면 0**, 반대면 음수입니다.
- 외적: **순서를 바꾸면 방향이 반대**입니다($a\times b = -b\times a$). 방향은 오른손 법칙으로 정합니다. $\hat x\times\hat y=\hat z$
- 점 + 점은 의미가 없습니다. 점 − 점 = 벡터, 점 + 벡터 = 점입니다.

```js
const dot = (a, b) => a[0]*b[0] + a[1]*b[1] + a[2]*b[2];  // 내적: 성분끼리 곱해서 모두 더함
const cross = (a, b) => [                                   // 외적: 두 벡터에 수직인 벡터
  a[1]*b[2] - a[2]*b[1],                                    //   x 성분
  a[2]*b[0] - a[0]*b[2],                                    //   y 성분
  a[0]*b[1] - a[1]*b[0],                                    //   z 성분
];                                                          // 외적 끝
const len = v => Math.hypot(...v);                          // 벡터 길이 √(x²+y²+z²)

// 예제 1: 사잇각 — cosθ = (a·b) / (|a||b|)
const a = [1, 1, 0], b = [0, 1, 1];                         // 두 벡터
const cos = dot(a, b) / (len(a) * len(b));                  // 1 / (√2·√2) = 0.5
console.log(Math.acos(cos) * 180 / Math.PI);                // 60 (도)

// 예제 3: 삼각형의 법선과 넓이
const P0 = [1,0,0], P1 = [0,1,0], P2 = [0,0,1];             // 삼각형 꼭짓점 3개
const u = P1.map((v, i) => v - P0[i]);                      // 변 u = P1 − P0 = (−1, 1, 0)
const v = P2.map((x, i) => x - P0[i]);                      // 변 v = P2 − P0 = (−1, 0, 1)
const n = cross(u, v);                                      // (1, 1, 1): 면에 수직인 방향
console.log(n.map(x => x / len(n)));                        // 단위법선 (1,1,1)/√3
console.log(len(n) / 2);                                    // 넓이 = 평행사변형의 절반 = √3/2
console.log(Math.atan2(len(n), dot(u, v)) * 180 / Math.PI); // 사잇각 60° (atan2는 0~180° 전 구간을 정확히 줌)
```

## 2. 행렬 곱의 두 가지 규칙

- **행렬의 열 = 기저 축(x, y, z)이 가는 곳**입니다. 이렇게 보면 스케일·회전 행렬을 외우지 않아도 만들 수 있습니다.
- $M_1 M_2 M_3\,v = M_1(M_2(M_3 v))$ → **오른쪽(v에 가까운 것)이 먼저** 적용됩니다.
- **교환법칙 ✗**: $TR \ne RT$입니다. 결합법칙은 성립하므로 여러 행렬을 미리 하나로 곱해 둘 수 있습니다. GPU가 빠른 이유입니다.

| 식 | 결과 (달의 예) |
|---|---|
| $R_z \cdot T \cdot p$ | 먼저 옮기고 돌림 → 원점 주위를 **공전**하며, 한 면이 늘 안쪽을 향함 |
| $T \cdot R_z \cdot p$ | 먼저 돌리고 옮김 → 제자리 **자전**만 함 |

```js
const rotZ = deg => p => {                                  // z축 회전 함수를 만든다
  const t = deg * Math.PI / 180;                            // 도 → 라디안
  return [Math.cos(t)*p[0] - Math.sin(t)*p[1],              // x' = cos·x − sin·y
          Math.sin(t)*p[0] + Math.cos(t)*p[1], p[2]];       // y' = sin·x + cos·y, z는 그대로
};                                                          // rotZ 끝
const move = p => [p[0] + 2, p[1], p[2]];                   // x로 2만큼 이동
console.log(rotZ(90)(move([0,0,0])));                       // R·T·p = (0, 2, 0) → 궤도를 따라 돌아감 (공전)
console.log(move(rotZ(90)([0,0,0])));                       // T·R·p = (2, 0, 0) → 위치는 그대로, 방향만 바뀜 (자전)
```

## 3. 스케일·회전

$$S=\begin{bmatrix}s_x&0&0\\0&s_y&0\\0&0&s_z\end{bmatrix},\quad
R_z(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta&0\\ \sin\theta&\cos\theta&0\\0&0&1\end{bmatrix}$$

- 스케일: 대각선에 배율을 넣습니다. 축마다 다르면 모양이 찌그러지고(5주차 법선 문제), 음수면 반사됩니다.
- **행렬식(det)** = 넓이·부피 배율입니다. det < 0이면 뒤집힘, det = 0이면 납작해져서 되돌릴 수 없습니다.
- 회전 행렬의 성질: det = 1이고, **역행렬 = 전치**($R^{-1}=R^T$)라 되돌리기가 쉽습니다.
- 3D 회전도 순서가 중요합니다($R_xR_y \ne R_yR_x$).
- $R_y$만 부호가 반대로 보이는 이유: 회전 순서가 z → x이기 때문입니다.
- **임의 축 회전**은 두 가지 방법으로 같은 결과를 얻습니다.
  - ① 로드리게스 공식 $R=\cos\theta\,I+\sin\theta\,[\hat n]_\times+(1-\cos\theta)\hat n\hat n^T$
  - ② $R_z(\alpha)R_y(\beta)R_z(\theta)R_y(-\beta)R_z(-\alpha)$: 축을 z축으로 눕힌 뒤 돌리고 다시 세웁니다. 이처럼 $AMA^{-1}$ 꼴로 "좌표계를 바꿔서 계산하고 되돌리는" 방식은 앞으로도 계속 나옵니다.
  - 두 방법 모두 축은 **반드시 정규화**해야 합니다(길이 1).

```js
// 로드리게스 공식: 단위벡터 n을 축으로 deg만큼 회전하는 3×3 행렬
function rodrigues([x, y, z], deg) {                        // n = (x, y, z), 길이 1이어야 함
  const t = deg * Math.PI / 180;                            // 도 → 라디안
  const c = Math.cos(t), s = Math.sin(t), k = 1 - c;        // 자주 쓰는 값 미리 계산
  return [                                                  // 행 단위로 반환
    [c + x*x*k,   x*y*k - z*s, x*z*k + y*s],                // 1행
    [y*x*k + z*s, c + y*y*k,   y*z*k - x*s],                // 2행
    [z*x*k - y*s, z*y*k + x*s, c + z*z*k],                  // 3행
  ];                                                        // 행렬 끝
}                                                           // rodrigues 끝
const r3 = 1 / Math.sqrt(3);                                // (1,1,1)을 정규화한 성분
console.log(rodrigues([r3, r3, r3], 120));                  // [[0,0,1],[1,0,0],[0,1,0]] → x→y→z→x로 한 칸씩 돌아감 (예제 5)
```

## 4. 이동과 동차좌표

- 3×3 행렬로는 이동을 **절대** 표현할 수 없습니다. 어떤 행렬 M이든 $M\cdot 0=0$이라 원점을 못 옮기기 때문입니다.
- 해결책은 좌표를 하나 더 붙인 $(x,y,z,\mathbf{w})$와 **4×4 행렬**입니다. 이동량은 **마지막 열**에 넣습니다.

$$\begin{bmatrix}1&0&0&t_x\\0&1&0&t_y\\0&0&1&t_z\\0&0&0&1\end{bmatrix}\begin{bmatrix}x\\y\\z\\1\end{bmatrix}=\begin{bmatrix}x+t_x\\y+t_y\\z+t_z\\1\end{bmatrix}$$

| | w | 이동하면 | 예 |
|---|---|---|---|
| 점 (위치) | **1** | 값이 바뀜 | 정점, 카메라 위치 |
| 벡터 (방향) | **0** | 그대로 (t × 0 = 0) | **법선**, 광선 방향 |

- 마지막 행을 `(0,0,0,1)`이 아닌 값으로 바꾸면 w ≠ 1이 되어 w로 나눠야 합니다. 이것이 **사영(원근) 변환**이고 4주차의 원근 투영입니다.

## 5. 변환의 종류

| 종류 | 포함 | 보존하는 것 | det |
|---|---|---|---|
| 선형 | 회전·스케일·전단·반사 (3×3) | 원점, 직선, 평행 | 자유 |
| 아핀 | 선형 + 이동 (4×4, 마지막 행 `0 0 0 1`) | 직선, 평행, 비율 (길이·각도는 X) | 자유 |
| 강체 | 회전 + 이동만 | **거리, 각도** (모양 그대로) | +1 |

- 아핀변환은 직선을 직선으로 유지합니다. 그래서 **정점 3개만 변환하면 삼각형 내부가 저절로 맞아** 래스터화가 성립합니다.
- 강체변환의 역행렬은 계산이 거의 없습니다. $\begin{bmatrix}R&t\\0&1\end{bmatrix}^{-1}=\begin{bmatrix}R^T&-R^Tt\\0&1\end{bmatrix}$이고, 4주차 뷰 행렬에서 이 성질을 씁니다.
