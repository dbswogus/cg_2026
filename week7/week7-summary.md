# 7주차 요약 — 전역 조명, Ray Tracing, Path Tracing

출처: [7주차 강의](https://cg.catholic.ac.kr/~mgchoi/CG/weeks/week07/) · 키워드: 직접광·간접광, GI, 광선-구 교차, BVH, path tracing, photon mapping, 그림자·반사·굴절

> **한 줄 요약**: 지금까지는 표면 하나씩 "광원 → 표면"만 계산했다(local). 이번 주는 픽셀에서 **광선을 쏴서** 무엇에 맞는지 찾고(ray tracing), 다른 표면에서 튕겨 온 빛까지 계산한다(global illumination).

## 1. 용어 구분

| 용어 | 뜻 |
|---|---|
| **직접광** | 광원 → 보이는 표면 → 카메라. 중간에 막히면 그림자 |
| **간접광** | 광원 → **다른 표면** → 보이는 표면 → 카메라 (붉은 벽 옆이 붉게 물드는 색 번짐) |
| **Local illumination** | 각 표면을 그 지점의 광원·재질·법선만으로 계산 (5·6주차) |
| **Global illumination (GI)** | 표면 사이에 빛이 오가는 것까지 계산하거나 근사 |

- "직접/간접"은 **빛의 경로**를, "local/global"은 **렌더러가 고려하는 범위**를 말합니다. 6주차의 상수 ambient와 AO는 간접광을 **흉내 낸 근사**입니다.
- 래스터화(삼각형 → 픽셀)는 빠릅니다. 그림자는 그림자맵, 반사는 환경맵처럼 **따로 준비한 것**으로 보충합니다.

## 2. Ray tracing — 카메라에서 거꾸로 쏘기

- 실제 빛은 광원 → 물체 → 눈 순서(forward)로 오지만, 이 방식은 대부분의 광선이 카메라에 닿지 않아 낭비입니다.
- 그래서 **카메라 → 픽셀 방향으로 역추적(backward)** 합니다. 픽셀마다 광선을 하나 쏘고 **가장 가까운 교차점**을 찾습니다.

### 광선-구 교차

광선 $p(t)=o+t\,d$를 구 $|p-c|^2=r^2$에 대입하면 t에 대한 2차방정식이 됩니다.

$$(d\cdot d)t^2+2d\cdot(o-c)\,t+(o-c)\cdot(o-c)-r^2=0$$

```glsl
float hitSphere(vec3 ro, vec3 rd, vec3 center, float radius) { // 광선 시작점, 방향, 구 중심, 반지름
  vec3 oc = ro - center;                                    // 구 중심 → 광선 시작점
  float a = dot(rd, rd);                                    // t² 계수 (단위 방향이면 1)
  float halfB = dot(oc, rd);                                // t 계수의 절반 (계산을 줄이는 형태)
  float c = dot(oc, oc) - radius * radius;                  // 상수항
  float disc = halfB * halfB - a * c;                       // 판별식
  if (disc < 0.0) return -1.0;                              // 음수면 안 맞음
  float root = sqrt(disc);                                  // 제곱근 한 번만 계산
  float t = (-halfB - root) / a;                            // 가까운 교차점
  if (t > 0.002) return t;                                  // 앞쪽에 있으면 사용 (0.002: 자기 자신에 다시 맞는 것 방지)
  t = (-halfB + root) / a;                                  // 구 안에서 출발했으면 먼 교차점
  return t > 0.002 ? t : -1.0;                              // 그것도 뒤쪽이면 안 맞음
}
```

- 검산: (0,0,5)에서 −z로 쏘면 반지름 1 구에 t = 4에서 맞습니다. 구 안 (0,0,0)에서 쏘면 t = 1에서 맞고, 옆으로 비켜 쏘면 −1(안 맞음)입니다.
- 교차점 $p=o+td$를 구하면 법선 $N=\text{normalize}(p-c)$로 조명을 계산합니다.

### 교차점에서 새로 쏘는 광선

| 광선 | 확인하는 것 | 효과 |
|---|---|---|
| **그림자 광선** (교차점 → 광원) | 중간에 다른 물체가 있나 | 일식·월식, 접촉 그림자 |
| 반사 광선 `reflect(rd, N)` | 거울에 비친 것 | 거울·금속에 다른 물체가 보임 |
| 굴절 광선 `refract(rd, N, eta)` | 유리 안팎으로 꺾인 경로 | 유리구 너머의 왜곡 |

### BVH — 검사 횟수 줄이기

- 삼각형이 수십만 개면 모두 검사할 수 없습니다. **물체를 상자(bounding volume)로 묶은 계층 구조**를 만들어 두고, 상자에 안 맞으면 그 안의 물체는 전부 건너뜁니다.
- 탐색 순서: 광선–상자 검사 → 맞은 자식 상자로 내려감 → 잎에서 광선–삼각형 검사 → 가장 가까운 t를 선택
- **RT Core**(NVIDIA)와 Apple M5의 하드웨어 가속은 BVH 탐색과 삼각형 교차를 빠르게 합니다. **재질·조명 계산과 광선을 몇 개 쏠지는 여전히 셰이더의 몫**입니다.
- 이 수업의 WebGL2 실습은 BVH 없이 구 3개를 매번 직접 검사합니다.

## 3. 빛 경로를 찾는 방법 비교

| 방식 | 경로 | 장점 / 주의 |
|---|---|---|
| 기본 ray tracing (실습 1) | 픽셀 → 첫 표면 → 광원으로 그림자 광선 | 그림자 이해가 쉬움. 간접광 없음 |
| Whitted 방식 | 픽셀 → 표면 → 반사·굴절 방향으로 재귀 | 거울·유리에 강함. 거친 표면의 간접광은 부족 |
| **Path tracing** | 교차점마다 방향을 **무작위로** 골라 경로를 이어 가고 여러 표본을 평균 | 일반적인 간접광에 강함. **표본이 적으면 노이즈(점무늬)** |
| **Photon mapping** | 광원에서 광자를 쏘아 저장 → 카메라 교차점 주변에서 조회 | 유리·물이 만드는 **집광 무늬(caustic)** 에 강함. 저장 공간과 조회 반경 선택 필요 |

## 4. 실습 1 — 기본 ray tracing으로 일식·월식

시작 코드 ZIP의 `task1.js` TODO 1 → 2 → 3을 채웁니다. 화면 전체를 덮는 사각형을 하나 그리고, **픽셀 셰이더에서 광선을 추적**합니다.

```glsl
// TODO 1: 픽셀마다 카메라 광선 만들기 (4주차 lookAt과 같은 축 만들기)
vec2 uv = (2.0 * pixel - uRes) / uRes.y;                   // 픽셀 좌표 → 화면 중앙이 (0,0), 세로 −1~1
vec3 target = vec3(0.0, 0.0, -1.8);                        // 바라볼 점
vec3 forward = normalize(target - eye);                    // 앞 방향
vec3 right = normalize(cross(forward, vec3(0.0, 1.0, 0.0))); // 오른쪽 = 앞 × 위
vec3 up = cross(right, forward);                           // 진짜 위쪽
return normalize(1.7 * forward + uv.x * right + uv.y * up); // 1.7이 클수록 시야각이 좁음

// TODO 3 핵심: 그림자 광선 — 교차점에서 별 쪽으로 쏴서 막히는지 확인
vec3 toStar = uBodies[0].xyz - p;                          // 교차점 → 별
float lightDistance = length(toStar);                      // 별까지 거리
vec3 L = toStar / lightDistance;                           // 별 방향 (단위)
int blockerId;                                             // 가로막은 물체 번호를 받을 변수
float blockerT = traceScene(p + N * 0.004, L, blockerId);  // 표면에서 살짝 띄워 출발 (자기 자신에 맞는 것 방지)
float visible = (blockerId > 0 && blockerT < lightDistance - 0.004) ? 0.0 : 1.0; // 별보다 앞에서 막히면 그림자
float diffuse = max(dot(N, L), 0.0);                       // 5주차 람베르트
return color * (ambient + visible * diffuse * power);      // 그림자면 직접광 0, ambient만 남음
```

- **일식**: 별 → 위성 → 행성 순서로 늘어서서, 위성의 그림자가 행성에 떨어집니다.
- **월식**: 별 → 행성 → 위성 순서로 늘어서서, 행성의 그림자가 위성을 덮습니다.
- 「그림자 광선」을 끄면 식이 사라집니다. 이 차이를 캡처하세요.

| 증상 | 원인 |

| 표면에 점무늬 그림자가 생김 (shadow acne) | 그림자 광선을 표면에서 바로 출발 → `p + N*0.004`처럼 띄우기 |
